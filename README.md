# joelisjoel.org

Joel's homepage: thoughts, projects and an archive of browser toys,
published at [joelisjoel.org](https://joelisjoel.org/) (joelisjoel.com
redirects there).

**To change what's on the homepage, edit [`_data/home.yml`](_data/home.yml).**
Each section shows its first three items and folds the rest away; every
section also has its own page (`/about/`, `/thoughts/`, `/projects/`,
`/archive/`).

| Path | What it is |
|---|---|
| `_data/home.yml` | All homepage content |
| `linkme/` | The links page that replaced Linktree |
| `snake/`, `snake3/` | Snake 2.5D and Snake 3D |
| `cube/` | The rotating cube demo |
| `metacube/` | A cube of six tiny dioramas |
| `worldview/`, `globe2/` | The World Pulse globe |

Skywyrm, the dragon game, has its own home at [skywyrm.io](https://skywyrm.io)
([joelisjoel/skywyrm](https://github.com/joelisjoel/skywyrm)).

GitHub Pages builds the `main` branch with Jekyll. See [CLAUDE.md](CLAUDE.md)
for how the site is put together and how to add things.
